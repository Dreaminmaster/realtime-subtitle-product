# Realtime Subtitle v2.9.1

This patch release fixes the regressions reported after the hardware-aware
recognition update and tightens several product interactions.

## Translation

- Apple Translation connection tests now choose a source language different
  from the selected destination, so English is no longer tested as `en → en`.
- Same-language translation requests return the original text safely.
- Missing Apple language assets are explained with the failing language pair;
  raw backend errors are logged instead of being rendered as subtitle text.
- The destination language is a direct, non-editable dropdown.

## Models and controls

- A model is marked installed only when a complete faster-whisper snapshot can
  be resolved and loaded. Partial Hugging Face folders and lock files no longer
  count as successful downloads.
- The enhanced-recognition button immediately shows its active state and keeps
  clear failure or cancellation feedback on the Recognition page.
- Combo boxes use a system chevron without a separate dark trailing block;
  spin-box chrome and oversized form stretching were removed.

## Live sessions

- Transcript-only sessions hide the playback transport.
- The caption overlay is explicitly configured as a non-activating macOS panel
  to prevent focus stealing and window flashing during text updates.
- Endpointing respects configured silence values up to two seconds. A likely
  lower-case continuation after a short pause revises the previous subtitle
  instead of always starting a new row.

## Verification

- 636 automated tests pass.
- The native Apple Translation helper was compiled with the macOS 26.5 SDK and
  verified with both same-language and installed Chinese-to-English requests.
- Deterministic UI captures cover Live, Apple Translation, target-language
  menus, enhanced recognition, appearance, system language, and session
  playback.
