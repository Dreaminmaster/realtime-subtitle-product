# Realtime Subtitle v2.10.0

## 中文

v2.10.0 把实时字幕从“整句结束后一次出现”升级为可验证的流式状态模型。

- 草稿、稳定和最终三级文本在同一字幕原位更新；稳定前缀不会随下一轮推理随意改变，只有最终文本进入会话历史。
- 参考 LocalAgreement 的连续一致确认，并结合 VAD、静音、标点、未完成短语、语言、持续时间和词数进行语义断句。
- 增量翻译只处理稳定前缀，按服务速度防抖；会话和文本版本会取消过期结果，慢服务不会阻塞识别或 UI。
- 节能 / 均衡 / 最高性能分别限制识别线程、模型 worker、翻译并发、草稿频率和上下文长度；均衡仍是默认。
- 悬浮字幕和历史会话在窄窗口自动换行，不横向滚动；草稿与稳定状态使用克制的文本和透明度差异，不闪烁。
- 新增隐私安全的合成测试音频生成器、短语音流式基准、30 分钟声学工作负载和运行指标记录。
- 完整回归测试 693 项通过。

本版本不会伪报外部翻译可用性。Apple Translation 需要 macOS 26、受支持的语言对和已下载系统语言资源；LM Studio 与在线 API 需要对应服务实际在线。连接测试以当前服务、地址、模型、语言和凭据为准。

## English

v2.10.0 replaces sentence-at-a-time output with a measured streaming caption lifecycle.

- Partial, Stable and Final text updates one caption in place. Stable prefixes remain monotonic and only final text enters session history.
- LocalAgreement-inspired agreement works with semantic endpointing across VAD, silence, punctuation, incomplete phrases, language, duration, and word limits.
- Incremental translation operates on stable prefixes with provider-aware debounce. Session and source revisions invalidate obsolete responses, and slow providers remain outside recognition and UI threads.
- Efficient, Balanced and Maximum profiles bound ASR threads, model workers, translation concurrency, draft cadence, and context length. Balanced remains the default.
- Floating captions and session history wrap at narrow widths without horizontal scrolling. Partial and Stable states use restrained textual and opacity cues without animation.
- The repository now includes a privacy-safe synthetic fixture generator, short streaming benchmark, 30-minute acoustic workload, and runtime metric collection.
- The full regression suite passes 693 tests.

External providers are not reported ready merely because a bridge or setting exists. Apple Translation requires macOS 26, a supported pair, and downloaded system language assets; LM Studio and online APIs require their actual services to be reachable. Connection status is scoped to the current provider, endpoint, model, language, and credential.

See [`streaming-architecture-research.md`](streaming-architecture-research.md) and [`performance-benchmark.md`](performance-benchmark.md) for sources, licenses, benchmark data, and remaining limits.
