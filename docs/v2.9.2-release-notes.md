# Realtime Subtitle v2.9.2

## 中文

v2.9.2 重点修复字幕独立运行、启动耗时和持续发热问题，并让单语言识别与环境噪声处理更容易使用。

- 字幕会话开始后，控制中心立即隐藏，macOS 进程切换为辅助应用模式；悬浮字幕使用非激活面板、跨桌面与固定层级，不再依赖主窗口占据前台。
- 增强识别模型改为字幕启动后后台加载，慢模型只保留最新一句待修正，旧句不会排队持续消耗 CPU。
- Auto 增强方案在 Apple Silicon 上使用 `turbo`；`large-v3` 仅在手动选择“高准确率”时启用，并在界面提示额外温度与 CPU 开销。
- Live 页新增“说话语言”快捷选择，单语言会话可跳过反复语言检测；识别设置页保持双向同步。
- 新增关闭、均衡、强力三档自适应噪声门限，以较低开销抑制稳定环境噪声，同时保留原始录音和 ASR 音频。
- 局部字幕刷新间隔调整为约 0.8 秒，减少 CPU 上重复的整段推理，最终字幕延迟不受影响。
- 外观预览的深色 / 浅色背景改为上下排列，字幕仍可拖动，长句不再被左右窄列挤压。
- 本地真实配置测试中，包含 `large-v3` 增强计划的管线准备时间由约 25 秒降至约 1.3 秒，增强模型此时尚未阻塞启动。

## English

v2.9.2 focuses on independent caption-only operation, startup latency, sustained thermal load, and easier single-language recognition.

- Starting a session immediately hides the control center and moves the macOS process into accessory mode. The overlay is a non-activating, all-Spaces floating panel and no longer depends on a foreground main window.
- Enhanced recognition loads after captions start and keeps only the latest pending correction, preventing stale phrases from queueing and consuming CPU long after they were spoken.
- Auto uses `turbo` on Apple Silicon. `large-v3` is reserved for an explicit Accurate choice, with a clear CPU and heat warning.
- Live now exposes a Spoken language selector synchronized with Recognition settings. Locking one language avoids repeated language detection.
- Off, Balanced, and Strong adaptive noise-gate modes suppress steady room noise with low overhead while leaving recorded and transcribed audio unchanged.
- Partial captions refresh at about 0.8 seconds to avoid redundant whole-buffer CPU inference without delaying final captions.
- Appearance preview surfaces are stacked vertically so draggable long subtitle lines retain their width.
- A real local configuration with a `large-v3` refinement plan prepared the pipeline in about 1.3 seconds instead of about 25 seconds because the larger model no longer blocks startup.

Native DMGs are published separately for Apple Silicon (`arm64`) and Intel (`x86_64`). Community builds remain unsigned and not notarized.
