# Realtime Subtitle v2.9.0

This release adds an optional, hardware-aware accuracy pass while preserving
the low latency of the existing live model.

## Recognition

- The current model still provides partial and immediate captions.
- A recommended larger local model can reprocess finalized audio and correct
  the same subtitle line, translation revision, and saved transcript segment.
- Auto selects Small on Intel, Turbo on mainstream Apple Silicon, and
  Large-v3 on Apple Silicon with at least 24 GB of memory.
- Fast, Balanced, and Accurate manual profiles are also available.
- Larger models are downloaded on demand. They are not bundled in the DMG.
- Refinement runs in an isolated one-worker queue and falls back to the
  standard result without interrupting the session if anything fails.

## Verification

- 628 automated tests cover configuration, hardware matching, model readiness,
  same-line correction, merged and out-of-order phrase revisions, stale-session
  safety, UI behavior, recordings, translation, and release infrastructure.
- `tools/compare_recognition_quality.py` compares two installed models on one
  16-bit PCM WAV and can report word error rate from a reference transcript.
- Native DMGs are built separately for Apple Silicon and Intel.
