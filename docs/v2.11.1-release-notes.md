# Realtime Subtitle v2.11.1

v2.11.1 is a Windows first-launch reliability patch based on a real ASUS
Windows 10/11 installation log.

## Fixed

- Replaced the Windows `os.execve` handoff with a monitored `pythonw.exe`
  child process.
- Gave the setup launcher and product dashboard independent single-instance
  locks so the handoff cannot be mistaken for a duplicate dashboard.
- Kept the setup window visible until the dashboard survives imports and first
  paint.
- Added `app-startup.log` capture plus a visible retry/open-logs failure state.
- Added a native Windows Qt event-loop startup smoke test to the release CI.

The environment shown in the submitted log was installed correctly; this
patch targets the transition immediately after the final `Ready` event.
