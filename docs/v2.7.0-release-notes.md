# Realtime Subtitle 2.7.0

## 中文

- 以“实时字幕”为主界面，仅保留“会话”和统一“设置”两个一级入口。
- 保存会话可选完整录音；历史页支持音频回放、进度拖动以及点击字幕跳转。
- 字幕外观提供实时预览与 macOS 原生颜色面板，背景透明度不再影响文字颜色。
- 新增 macOS 26+ Apple 本地翻译，使用系统管理的语言包。
- 模型中心支持推荐模型、Hugging Face 搜索与兼容 faster-whisper 的自定义仓库。
- ARM64 与 Intel 安装包继续分别原生构建。

## English

- Live Subtitles is the primary workspace; Sessions and one unified Settings area complete the navigation.
- Saved sessions can optionally keep full audio, with timeline playback and click-to-seek transcript lines.
- Appearance now has a faithful live preview and the native macOS color panel.
- Apple on-device Translation is available on macOS 26+ with installed language assets.
- The model center supports recommendations, Hugging Face search, and compatible custom faster-whisper repositories.
- Native ARM64 and Intel DMGs are built separately.
