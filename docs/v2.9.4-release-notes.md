# Realtime Subtitle v2.9.4

## 中文

v2.9.4 重点修复长字幕和窗口缩放，并把可下载的离线翻译变成完整产品流程。

- 很长的原文与译文会在当前字幕框内自然换行，不会被右侧裁掉，也不会因为视觉换行而创建新字幕。
- 会话时间轴会随控制中心宽度重新排版，移除底部横向滚动条。
- Agnes AI 与自定义 OpenAI-compatible 接口合并为“在线 API”，通过预设切换，减少重复入口。
- 翻译页可按需下载、校验、选择和删除轻量英中 / 中英离线模型；识别模型与翻译模型明确分区。
- 离线翻译模型保存在用户目录，不进入 DMG；未下载时 App 会显示明确状态与操作。
- 均衡模式单段最长九秒，上下文合句长度同步收紧，减少一条字幕过长的问题。
- 草稿翻译刷新间隔进一步缩短；节能模式继续保留低发热策略。

## English

v2.9.4 focuses on long-caption layout, responsive session history, and an end-to-end optional offline-translation workflow.

- Long source and translated text wraps inside the current floating caption instead of clipping or creating a second caption.
- Session transcript rows reflow with the control-center width and no longer expose a horizontal scrollbar.
- Agnes AI and custom OpenAI-compatible endpoints share one Online API provider with presets.
- Lightweight English↔Chinese offline models can be downloaded, verified, selected, and removed on the Translation page.
- Recognition and translation downloads are clearly separated; translation models stay optional and outside the DMG.
- Balanced acoustic segments are capped at nine seconds and phrase-composer limits are shorter for more readable rows.
- Draft translations update sooner while Efficient mode remains available for lower thermal load.

Native DMGs are published separately for Apple Silicon (`arm64`) and Intel (`x86_64`). Community builds remain unsigned and not notarized.
