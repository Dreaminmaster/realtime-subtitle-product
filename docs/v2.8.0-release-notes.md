# Realtime Subtitle v2.8.0

这一版把“保存会话”从一份静态记录升级成真正可以回听、对照和导出的本地字幕资料。

- 录音回放改用 macOS 原生播放路径，支持播放、暂停、拖动进度和点击字幕跳转。
- 字幕按歌词方式跟随录音：当前句自动居中、提亮并放大。
- 导出只作用于当前选中的会话，可选择字幕、录音或两者；字幕内容遵循当前的双语、原文或译文查看方式。
- 外观预览中的字幕可以在深浅背景之间拖动，便于实时检查字号、颜色、透明度与对比度。
- 常用选项改为分段控件，其余下拉菜单使用无白边、无空白区域的应用内浮层。
- 缩短语音端点等待，提高部分识别刷新速度，并加强上下文续句与翻译提示，减少短暂停顿造成的碎句。

This release turns saved sessions into useful local playback and export artifacts.

- Native macOS recording playback with play, pause, seeking, and click-to-seek subtitle lines.
- Lyrics-style follow mode automatically centers and emphasizes the active subtitle.
- Export only the selected session as transcript, recording, or both; transcript output follows the current Both, Original, or Translation view.
- Drag the live subtitle preview across dark and light surfaces to check contrast while editing the style.
- Compact segmented choices and app-owned menus remove blank popup panels and make interactions more predictable.
- Faster endpointing and partial recognition, plus stronger phrase context, reduce latency and fragmented captions.

Native DMGs are provided separately for Apple Silicon (`arm64`) and Intel (`x86_64`). The community builds are unsigned and not notarized.
