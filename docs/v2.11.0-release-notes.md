# Realtime Subtitle v2.11.0

v2.11.0 adds a first-class Windows x64 product while keeping the same streaming
caption, session, playback, export, and model-management architecture used on
macOS.

## Windows

- Installable per-user setup EXE; Python is bundled and no administrator access
  is required.
- Native WASAPI loopback system-audio capture with selectable playback device;
  no VB-CABLE or output rerouting.
- Built-in Whisper Tiny and Apache-2.0 English↔Simplified Chinese offline
  translation models.
- LM Studio/local server and OpenAI-compatible online translation remain
  available; Apple-only controls are removed.
- Non-activating, always-on-top subtitle window with Windows-native taskbar and
  Alt-Tab behavior.
- Windows Local AppData paths, Segoe UI typography, Windows memory detection,
  and hardware-aware sustained performance settings.

## Shared product behavior

- Partial, Stable, and Final caption states update in place.
- Incremental translations are revision guarded and cannot overwrite newer
  text when a slow request returns late.
- Saved sessions, optional recordings, lyric-style playback, responsive
  transcript layout, and targeted export work from the same code path.
