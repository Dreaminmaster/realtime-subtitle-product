# Realtime Subtitle 2.5.1

## 中文

- 新增上下文断句合并：短暂停顿造成的未完句会复用同一条字幕，并在继续说话后自动补全原文和译文。
- 新增翻译修订保护：旧请求晚到时不会覆盖新句子，合并前产生的临时字幕也会自动移除。
- 强化本地与在线模型提示，把问句、命令和不完整短语都严格作为语音内容翻译，不再当作聊天请求回答。
- 对疑似助手式回答自动进行一次严格重试；连续异常响应会被拦截，不直接展示为译文。
- 重做语言页二级导航，移除 macOS 原生浅色标签栏和弹出选择框带来的主题割裂。
- 翻译服务改为无弹窗的四项选择器，并优化窄窗口下的表单宽度与中英文状态摘要。
- 重做模型列表与下载进度，移除旧版紫色嵌套卡片，统一紧凑暖色层级并补齐动态中文状态。
- 字幕窗口会自动限制到当前屏幕范围，并迁移旧版异常位置；外层保持透明，字幕卡片自身维持可读背景。
- 修复韩语续接时丢失词间空格，以及普通短句被过度合并的问题。

## English

- Added context-aware phrase composition: likely unfinished speech after a short pause now revises the same caption and translation.
- Added revision guards so stale translation results cannot overwrite newer text, while superseded partial rows are removed.
- Strengthened local and online prompts so questions, commands, and incomplete phrases are translated as quoted speech rather than answered as chat requests.
- Added automatic strict retry and response screening for assistant-like model replies.
- Replaced native light macOS sub-tabs and popup-heavy provider controls with consistent in-app navigation.
- Rebuilt translation settings for narrow windows with a popup-free four-provider selector and localized status summaries.
- Rebuilt model cards and download progress with compact product styling and localized live states.
- Clamped the caption overlay to the active display, migrated legacy off-screen placement, and kept the outer surface transparent while preserving readable caption backgrounds.
- Fixed Korean continuation spacing and prevented ordinary short sentences from being merged too aggressively.

Validation: 574 automated tests plus live LM Studio checks with `qwen2.5-coder-14b-instruct-mlx`, including question translation and an unfinished-phrase revision.
