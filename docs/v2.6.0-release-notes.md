# Realtime Subtitle 2.6.0

## 中文

- 内置基于 macOS ScreenCaptureKit 的系统声音采集，不再需要 BlackHole。
- 悬浮字幕的“主界面 / 隐藏”按钮可双向切换控制中心。
- 应用改为单实例，字幕浮层不再激活或抢占其他 App 的焦点。
- 工具条的 Save 改为语义明确的“导出”，用于生成额外的 TXT 快照。
- 模型下载完成后进度面板自动收起；外观应用成功后立即显示反馈。

## English

- Adds built-in ScreenCaptureKit system-audio capture with no BlackHole dependency.
- Makes the overlay Controls / Hide action a true two-way control-center toggle.
- Enforces one running instance and prevents the overlay from activating or stealing focus.
- Renames Save to Export to clarify that it creates an optional TXT snapshot.
- Automatically dismisses completed model progress and confirms Appearance changes in place.
