# Realtime Subtitle v2.9.3

## 中文

v2.9.3 让翻译从“整句结束后出现”升级为可逐步修正的实时草稿，同时进一步控制增强识别的持续发热。

- 讲话过程中，最新 PARTIAL 识别结果会按设置提前翻译；译文在同一行更新，最终定稿可靠覆盖草稿。
- 草稿翻译只用于屏幕预览，不会进入会话历史或导出；旧草稿、旧会话与已经定稿的结果都会被丢弃。
- Apple Translation 对固定语言组合复用一个原生 `TranslationSession`。本机测试首次初始化约 2.5 秒，第二次调用约 0.056 秒。
- Apple 最终翻译繁忙时，草稿不会排队抢占；最终结果保持优先。
- 翻译设置新增“仅最终译文 / 均衡 / 更实时”，不同服务采用不同的安全刷新间隔。
- 识别设置新增“节能 / 均衡 / 最高性能”。均衡与节能会在慢速增强识别后自动冷却，最高性能仍允许连续运行。
- 模型质量与运行负载分离：用户仍可选择 `large-v3`，不再因为降低发热而删除高配置选项。

## English

v2.9.3 upgrades translation from final-only output to a changing live draft while further bounding the thermal cost of enhanced recognition.

- The newest PARTIAL recognition result can be translated before the utterance ends; the same row is updated and the reliable FINAL result replaces the draft.
- Draft translations are display-only. They are session guarded, never persisted or exported, and discarded after finalization.
- Apple Translation reuses one native `TranslationSession` for a fixed language pair. Local validation measured about 2.5 seconds for initialization and 0.056 seconds for the second request.
- Best-effort Apple drafts skip when the service is busy instead of queueing ahead of a final translation.
- Translation offers Final only, Balanced, and Realtime modes with provider-aware request spacing.
- Recognition offers Efficient, Balanced, and Maximum runtime profiles. Balanced and Efficient cool down slow refinement passes; Maximum preserves continuous execution.
- Runtime workload is separate from model quality, so `large-v3` and other high-end choices remain available.

Native DMGs are published separately for Apple Silicon (`arm64`) and Intel (`x86_64`). Community builds remain unsigned and not notarized.
