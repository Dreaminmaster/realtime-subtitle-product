# Realtime Subtitle v2.8.1

This maintenance release removes ambiguity around recordings and model downloads, and tightens the visual hierarchy of saved sessions.

## Changes

- Live has three explicit session outcomes: **Temporary**, **Save subtitles**, and **Subtitles + recording**.
- Sessions saved without audio clearly explain why playback is unavailable; old sessions cannot be retroactively recorded.
- Saved transcript lines flow naturally without individual bubbles. During playback, only the active lyrics line receives a subtle accent and size change.
- The appearance preview renders the exact selected number of visible subtitle rows.
- Apple Translation failures expose installation guidance, a System Settings shortcut, and Apple’s official help page.
- “Target language” is now the clearer **Translate into**.
- The app distinguishes speech-recognition model downloads from translation models supplied by LM Studio or an API provider.
- Tiny/Base recognition models show an accuracy warning and recommend Small or Turbo where appropriate.
- Includes an implementation proposal for an opt-in, two-pass enhanced-accuracy recognizer in `docs/recognition-v2.9-proposal.md`.

Native DMGs are published separately for Apple Silicon (`arm64`) and Intel (`x86_64`). Community builds remain unsigned and unnotarized.
