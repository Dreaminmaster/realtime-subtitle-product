# Realtime Subtitle 2.5.2

## 中文

- 修复翻译连接状态残留：切换 Agnes AI、LM Studio 或自定义 API 后，旧的“连接成功”会立即失效。
- 连接结果现在绑定当前服务、API Key、接口地址、模型和目标语言；修改任一项都会显示“尚未测试当前设置”。
- 新增异步代次保护：旧服务的测试线程即使稍后返回，也不能覆盖新服务的界面状态。
- 开始字幕后控制中心从“最小化”改为完全隐藏，字幕更新不会再把大窗口带回前台。
- 悬浮字幕工具条新增“主界面”入口，可明确恢复控制中心。
- 运行中点击控制中心红色关闭按钮只隐藏主窗口，字幕和翻译继续工作；停止按钮结束会话，`⌘Q` 完全退出。
- App 允许在没有可见控制中心时继续运行悬浮字幕，并对启动失败、音频错误和管线错误保留自动恢复主界面的行为。

## English

- Fixed stale connection success after switching between Agnes AI, LM Studio, and custom APIs.
- Connection results are now scoped to the exact provider, API key, endpoint, model, and target language; changing any field marks the current settings as untested.
- Added async generation guards so a late result from an old provider cannot overwrite the current UI.
- The control center now hides completely instead of minimizing when captions start, preventing subtitle updates from restoring the large window.
- Added an explicit **Controls** action to the overlay toolbar.
- Closing the control center during a live session now hides only that window while captions continue; Stop ends the session and `⌘Q` quits the app.
- The app keeps the overlay alive without a visible control center while still restoring the main window for startup, audio, or pipeline errors.

Validation: 580 automated tests plus a native macOS Cocoa window-lifecycle smoke test.
