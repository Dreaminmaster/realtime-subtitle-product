# Realtime Subtitle 2.5.0

## 中文

- 新增应用全局 English / 简体中文即时切换。
- 移除冗余品牌横幅、内部口号与默认展开的开发诊断信息。
- System 页面改为可滚动的产品设置页，技术详情按需展开。
- 字幕可见条数支持 1–8 条自定义，向上滚动可回看本次会话历史。
- 翻译设置改为单一 Provider 选择器；Agnes AI、LM Studio 与自定义服务不再以外露快捷按钮堆叠。
- 修复“连接测试成功但实时字幕不翻译”的运行配置不同步问题，并自动补全 LM Studio / Agnes 的 `/v1` 地址。
- 新增本地会话历史，可查看、导出和删除；开始前可切换为不留记录的临时会话。
- 颜色选择改为原生色板，背景透明度改为滑杆，并与文字透明度完全分离。
- 更换带透明外缘的暖色 macOS 图标，避免 Dock 显示成实心方块。
- 首次启动不再被权限向导阻塞，麦克风权限在真正开始字幕时按需申请。
- 修复小屏幕和启动阶段内容被裁切的问题。

## English

- Added instant app-wide English / Simplified Chinese switching.
- Removed redundant branding, internal slogans, and developer-first diagnostics.
- Rebuilt System as a responsive, scrollable preferences page with collapsed technical details.
- Added a 1–8 visible-row setting while retaining in-session subtitle scrollback.
- Replaced exposed preset buttons with one provider selector for Agnes AI, LM Studio, and custom services.
- Fixed stale runtime settings that let connection tests pass while Live used an old translation configuration; endpoints now normalize `/v1` automatically.
- Added a local chat-style session library with view, export, delete, and no-history Temporary mode.
- Added a native color panel and background-opacity slider while keeping text fully opaque.
- Added a transparent-edge macOS icon so the Dock no longer renders a solid square.
- Removed the blocking first-launch permission wizard; microphone permission is requested when captions actually start.
- Fixed content clipping on smaller displays and during launch.

Validation: 558 automated tests, live LM Studio and Agnes API translation checks, and native ARM64/Intel release builds via GitHub Actions.
